Welcome. This book teaches you how to program a competition robot using the **NRL platform** (the *HEXA Command Hub*) — even if you have never written a single line of code before. We start from the very beginning: installing the software, understanding the hardware, and writing your first tiny program. By the end, you will be writing your own driver-controlled and fully autonomous robot programs, using motors, servos, a gamepad, sensors, and a live data display.

The book is built as a **path**. Each part assumes you have read the ones before it. If you are brand new, read it front to back. If you already know how to code, you can skim Part 1 and start at Part 2.

## The five parts

| Part | What it covers |
| --- | --- |
| **Part 1 — Foundations** | What the robot is, and just enough C++ to read every example in this book. |
| **Part 2 — Getting Started** | Installing the tools, understanding your hardware, creating a project, pairing, flashing, and your first working program. |
| **Part 3 — Programming the Robot** | One short chapter per building block: motors, driving, servos, the gamepad, the IMU, telemetry, the LED, the OLED, and power. |
| **Part 4 — Autonomous & Advanced** | Robots that drive themselves: the action system, closed-loop turns, and a gentle look at the control ideas underneath. |
| **Part 5 — Reference** | Worked examples, a troubleshooting guide, an API cheat-sheet, and a glossary. |

## What you need

- A Windows, macOS, or Linux computer with a free USB port.
- An **NRL kit**: a Robot board and a handheld Controller board (both are ESP32-S3 microcontrollers), a USB cable, motors, and servos.
- Curiosity. No prior programming experience is required.
